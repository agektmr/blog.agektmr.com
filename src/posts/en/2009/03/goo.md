On March 26, we launched a <a target="_blank" href="http://sandbox.home.goo.ne.jp/">sandbox environment</a> for OpenSocial support on <a target="_blank" href="http://home.goo.ne.jp/">goo Home</a>.

![][1]

The main features are as follows:

*   Core APIs (People, AppData, Activity)
*   Support for home, canvas, and profile views
*   Privacy controls for each user profile attribute
*   Comprehensive coverage of viral features such as requestCreateActivity, requestPermission, requestSendMessage, and requestShareApp
*   goo Home emoji feature
*   <a target="_blank" href="http://code.google.com/p/opensocial-jquery/">opensocial-jquery</a> feature

Not only is it in Japanese, but in terms of specification coverage, we are confident that it provides an ideal environment—more so than any existing container—for those getting started with OpenSocial for the first time.

We also put a lot of effort into writing the documentation. Since topics like permissions are rarely documented well elsewhere, I think you'll find it very helpful. Please be sure to check it out.
