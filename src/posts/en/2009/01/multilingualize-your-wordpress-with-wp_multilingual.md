I've been wanting to make this blog multilingual for a while, and I just found a good plugin to do it.

<a href="http://wordpress.org/extend/plugins/wp-multilingual/#post-5056" target="_blank">WP_Multilingual</a> is a multilingual plugin for WordPress. It's not an auto-translator; you have to post in each language, but those languages are tied to a single entry, and the viewer's preferred language is automatically detected using the request header. This is the ideal functionality I've been looking for.

Just one problem: <a href="http://wordpress.org/extend/plugins/fckeditor-for-wordpress-plugin/" target="_blank">Dean's FCKEditor</a>, which you must install along with WP_Multilingual, doesn't seem to work very well with Japanese. Ugh.

Anyway, it looks fine just for internationalization. I'll look for a solution regarding the editor.
