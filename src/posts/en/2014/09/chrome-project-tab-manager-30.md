Project Tab Manager, which [briefly gained niche popularity as the Chrome Extension that helps you get a girlfriend](http://blog.agektmr.com/2013/05/chrome-project-tab-manager-20.html), has reached version 3.0.

<!-- excerpt -->

Project Tab Manager is a Chrome Extension that monitors your window states so you can restore them at any time.

* Always have nearly 100 Chrome tabs open
* Chrome alone ends up consuming a huge amount of memory because of it
* Get distracted checking Twitter or Facebook (and Google+, of course!) while working

If this sounds like you, it's highly recommended.
By shifting the concept slightly from previous versions, I aimed for greater clarity and simplicity. Rather than managing projects, the focus is now on tracking sessions.

[![](https://3.bp.blogspot.com/-6wu9CtCZEh8/VB75NiKxizI/AAAAAAAAuJE/kNjxOU_3p88/s1600/screenshot4.png)](https://3.bp.blogspot.com/-6wu9CtCZEh8/VB75NiKxizI/AAAAAAAAuJE/kNjxOU_3p88/s1600/screenshot4.png)

Once you install [Project Tab Manager](https://chrome.google.com/webstore/detail/project-tab-manager/iapdnheekciiecjijobcglkcgeckpoia) (PTM), a project is automatically created for each open window.

[![](https://1.bp.blogspot.com/-DQAKjg37wAM/VB75Kxp5e7I/AAAAAAAAuIU/55GMdeK_w-8/s1600/readme_1.png)](https://1.bp.blogspot.com/-DQAKjg37wAM/VB75Kxp5e7I/AAAAAAAAuIU/55GMdeK_w-8/s1600/readme_1.png)

If you check the extension whenever you add or close tabs, you'll see that your tab states are being fully tracked. Try closing a window (instead of closing every tab individually). You'll notice the project remains in PTM, and clicking on it restores the original window.

If you find it annoying that projects get added even when you just opened a temporary window, simply close all tabs within that window. The project will be deleted.

You can also rename projects.

[![](https://1.bp.blogspot.com/-BNp5ALsq_To/VB75LF81rHI/AAAAAAAAuIY/U8VDbzQuM4A/s1600/readme_2.png)](https://1.bp.blogspot.com/-BNp5ALsq_To/VB75LF81rHI/AAAAAAAAuIY/U8VDbzQuM4A/s1600/readme_2.png)

[![](https://4.bp.blogspot.com/--RmUU-RZekQ/VB75L02ENuI/AAAAAAAAuJI/OHTrQCkJnU8/s1600/readme_3.png)](https://4.bp.blogspot.com/--RmUU-RZekQ/VB75L02ENuI/AAAAAAAAuJI/OHTrQCkJnU8/s1600/readme_3.png)

Clicking the ☆ on the right side lets you permanently add that page to the project so you can reopen it anytime.

[![](https://2.bp.blogspot.com/-ORxkqqmlZx8/VB75NRAxcqI/AAAAAAAAuI0/0A0wJ25LJj0/s1600/readme_6.png)](https://2.bp.blogspot.com/-ORxkqqmlZx8/VB75NRAxcqI/AAAAAAAAuI0/0A0wJ25LJj0/s1600/readme_6.png)

The ☆ is actually a bookmark, saved under "Other Bookmarks" organized by project. This means you can also open them from Chrome on mobile or on other computers, as long as your bookmarks are synced.

[![](https://4.bp.blogspot.com/-V8oOiTkMvIk/VB75MmRnOiI/AAAAAAAAuIs/i-YYPKnEE44/s1600/readme_5.png)](https://4.bp.blogspot.com/-V8oOiTkMvIk/VB75MmRnOiI/AAAAAAAAuIs/i-YYPKnEE44/s1600/readme_5.png)

In PTM's popup window, keyboard shortcuts are mapped to work as follows:

* **Tab, Shift+Tab:** Navigate between projects
* **Return:** Open project window
* **Right:** Expand project
* **Left:** Collapse project

If you set a shortcut key under "Keyboard Shortcuts" at the bottom of the Chrome extensions page (chrome://extensions), you can also easily open the popup itself.
