* Note: This article was originally published on May 2, 2012, and has been partially updated.

Have you heard of [HTML5Rocks](http://www.html5rocks.com/)? HTML5Rocks is one of the world's leading resources for HTML5-related information, packed with tutorials, samples, slides, videos, and more. Primarily maintained by Google's Chrome Developer Relations team, the site was originally English-only, but in May 2012, it introduced i18n (internationalization) support across nine languages and began adding [Japanese content](http://www.html5rocks.com/ja/).

[![](https://1.bp.blogspot.com/-C_eeFgO20Pc/UrJzmPTH6GI/AAAAAAAAnbg/qwwji8edaVA/s400/Screen+Shot+2013-12-19+at+13.17.26.png)](https://1.bp.blogspot.com/-C_eeFgO20Pc/UrJzmPTH6GI/AAAAAAAAnbg/qwwji8edaVA/s1600/Screen+Shot+2013-12-19+at+13.17.26.png)

While the amount of content is still limited, we hope it can serve as a comprehensive resource for developers who may have hesitated to read English documentation. Here are a few of the translated articles:

### [Reading Files in JavaScript Using the File APIs](http://www.html5rocks.com/ja/tutorials/file/dndfiles/)

A starter guide for reading and processing binary files in JavaScript using the File, FileList, and FileReader APIs.

### [Native HTML5 Drag and Drop](http://www.html5rocks.com/ja/tutorials/dnd/basics/)

Drag and drop is one of the core features of HTML5. This article explains how to enhance web applications by adding native drag-and-drop functionality.

### [Exploring the FileSystem APIs](http://www.html5rocks.com/ja/tutorials/file/filesystem/)

With the FileSystem API, applications can read and write files and directories within a protected, sandboxed file system on the user's local machine.

## Contributions Welcome!

Did you know that HTML5Rocks itself is actually developed as open source? Here is the repository:

[https://github.com/html5rocks/www.html5rocks.com](https://github.com/html5rocks/www.html5rocks.com)

And in fact—here is the main point—HTML5Rocks is looking for **Japanese translations of articles**. As is common with multilingual documentation, keeping translations up to date is genuinely challenging. That is why HTML5Rocks leverages its open-source nature to accept translations from the community. We have already received contributions from folks like [@kuu](http://github.com/kuu), [@ukyo](http://github.com/ukyo), [@Layzie](http://github.com/Layzie), [@pikotea](http://github.com/pikotea), and [@iizukak](https://github.com/iizukak), but many of the newer articles haven't been tackled yet.

If you're interested, please take a look at the [Style Guide](http://www.html5rocks.com/en/style-guide) first. Once you've translated an article, feel free to send a pull request. Also, with a recent design update, you can now include translator credits. Please refer to the Translations section of the Style Guide to add your name.

In the past, someone asked, "I'm hesitant to start translating because someone else might be working on the same thing." Since we've now migrated to GitHub, if you open an issue when you begin translating, we'll take that order into account when accepting pull requests.

If you have any questions, feel free to reach out on [Google+](http://google.com/+agektmr) or [Twitter](http://twitter.com/agektmr). We look forward to your contributions!
