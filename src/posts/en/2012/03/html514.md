Addy Osmani recently shared a collection of [online tools on Google+](https://plus.google.com/115133653231679625609/posts/7pozWtg1LcD), and since they looked really useful, I’d like to introduce them here.

## [DocHub.io](http://dochub.io/)

![](https://lh5.googleusercontent.com/u1IkaGdfHajwO8K4j6GJANsZHRjBGMymRu4FNElDyOUIIhZGEAV7IibwKv1v8S8Zh20UWT4q698Ap0d8V5DcbrnOH-EWth70UxLswVVVcsrhEqRJLiI)

API reference for CSS, HTML, JavaScript, DOM, jQuery, PHP, and Python. With incremental search support, it's something you'll want to keep open all the time while developing.

## [Dillinger.io](http://dillinger.io/)

![](https://lh4.googleusercontent.com/YjKYM_0wpHu9rHWbjuyGMFSw3BACetmUqyJGXnLgUHdA5cRGMekeUI_Lp_ULaYOoJ2N6S6g8qWnA-qByppXpkvteii0q8ow65p13rK-5h_po75ErrFQ)

A tool that lets you type Markdown—a syntax that has gained popularity recently through its use on GitHub—while previewing the rendered output visually. If you connect your Dropbox or GitHub account, you can also upload files directly. [Mou, a desktop app for Mac](http://mouapp.com/), was also introduced alongside it.

## [HTML5Please](http://html5please.com/)

![](https://lh4.googleusercontent.com/IpvnLNzjal1SgtJ1pyMQX7xT6nFwS_KmRfoZlHVnShdBeTyIiLLyMfBEUuluwQqoi0H2i1VvC15tpx3MflcPSj0ak5udotjak_lDfw8nIfBBuwP_aMk)

A handy site providing a list of HTML5 features you can use right now, recommendations based on browser support, and [polyfills (JS libraries that backfill features for unsupported browsers)](https://github.com/Modernizr/Modernizr/wiki/HTML5-Cross-Browser-Polyfills).

![](https://lh5.googleusercontent.com/eQnG5eLgg7Q3yaHTLWxtwipe9T_pRPLtazwgR_bgLWko5Ho14AWim03cCZE3M4FlT_6Xns4MVyU_UHF57hoOHbghkwYgeHyP77b8u9UPGA1VLDg2vH0)

And here is [its API](http://api.html5please.com/). By embedding widgets created here into your site, you can easily build UI that notifies users when a feature is unsupported. Browser support data is reportedly kept up to date using [caniuse.com](http://caniuse.com/).

## [CSS3Please](http://css3please.com/)

![](https://lh6.googleusercontent.com/qMvFENuCVC8sD8VdPeZEopBKQyp--Eh3u0fp_ZdizDbLGcn9eFUjNYnhcB8ULEUw8h4Uuvs2RzIuOkuZBVeRJdo5dr6_LwqIH9bn_yUWTPcKFhKiQ20)

A handy site where you can edit the displayed CSS inline, previewing the results in real time before copying and pasting.

## [CSS3 Playground](http://westciv.com/tools/gradients/)

![](https://lh4.googleusercontent.com/Ky4ZifQRo6PddFRGCo-6fDTN3bdpfHOLLALDeSoQintP2dRmjLVWq-4fFAQN41dkbSbvqmVnCeZnOe6lrpa22z_Uge8TGgCky3EhHTYIrnJiINoihwg)

A playground where you can tweak CSS3 properties while visually checking the output. It supports gradients, text properties, transforms, and more.

## [Responsive](http://mattkersley.com/responsive/)

![](https://lh6.googleusercontent.com/8VZ5FaPuQnqv1TublaAPMbguMKCNWPx_d5etotmtBn1JlyZzTXRct4NkNSgRXBWzNMMDvi0L9ESE5VR0JdCRL3YI0Z_yZo5t9v6bNFjS8xIIaqNVK7A)

Responsive web design is a concept for supporting a wide range of viewing environments—from smartphones to desktops—with a single codebase. This tool lets you view how a site built with responsive web design looks across various screen sizes all at once.

## [CanIUse.com](http://caniuse.com/)

![](https://lh5.googleusercontent.com/tqXpXIb9jOEgTCm9cIoEUgppocpjKKja0WfdKYit2dhRGTmOzA6nxoYU9-byUxyc9XDf936aAk2hlVWWTh_4X73o4ZPl_s5WYnLW2R6F4_BnyCS28oE)

Many of you are probably already familiar with it, but this is the definitive site for checking browser support for HTML5 features.

## [HTML5 Readiness](http://html5readiness.com/)

![](https://lh4.googleusercontent.com/VrSGIsxKiEUJDJrSneSf_oUlCN68ryeG8Y18K61s0rgHpXIsyRJvl9Ov7G7PZcAOPeMPOb-0mPwn6KIyd1dySbYkMH2vuZtNsu04fRY5UBLmtjiXz3g)

Another well-known site for checking HTML5 support, but rather than looking up individual APIs, its main focus is giving you a visual sense of how HTML5 implementation is progressing.

## [Browserstack](http://www.browserstack.com/)

![](https://lh4.googleusercontent.com/x3pPfhf1YYjKWsbfCtvJqW8ZkYFF0SomtSQlufYZwnY3Lp2_S3eGX8DA_74hXRi99bh7wPHCjXxKD4f2ZZlBVCHXguN6uBBXNwmnwMsjGBhKjCDQXZA)

A paid service that lets you test across a wide variety of browsers, both old and new.

## [Grunt](https://github.com/cowboy/grunt)

A command-line build tool for JavaScript projects. It handles everything from file concatenation to validation, minification, and unit testing. It's still in beta, but it's very powerful.

## [jsPerf](http://jsperf.com/)

![](https://lh5.googleusercontent.com/xSrXIUT_Q1r97-M9Hf95uTpW25kNSSYcC9DWDt-ARcjRrtPP1K2OCerjizu173XLPgCt_yrET5biK8C9myRx3GThIJs7yOFzl8ejSsQxFDZiU0ppOjY)

A site for creating and sharing various JavaScript test cases. Just browsing the [existing test cases](http://jsperf.com/browse) is insightful enough. It also supports cross-browser comparisons powered by [Browserscope.org](http://www.browserscope.org/).

## [jsconsole](http://jsconsole.com/)

![](https://lh4.googleusercontent.com/HlqykRPvhQ7heNg8FlsU-LD2fItkCfuJwIt_yKOSfToLYvNo6z_k_S14Vwl6ZYwPuCoqNi4ZN1oTf8knuIaC8kyCb6abTVddoqnTVdEu50mLpwEfEOI)

A web app featuring a JavaScript console and debugger. Now that tools like [Adobe Shadow](http://labs.adobe.com/technologies/shadow/) are available, it's hard to say how essential it will remain, but the debugging feature that connects to iOS and Android browsers is fantastic.

## [Chrome DevTools AutoSave](https://github.com/NV/chrome-devtools-autosave)

[http://addyosmani.com/blog/autosave-changes-chrome-dev-tools/](http://addyosmani.com/blog/autosave-changes-chrome-dev-tools/)

While Chrome DevTools' revision history and save capabilities are already convenient, this extension automatically saves your changes, essentially allowing you to develop directly within Chrome DevTools. Addy Osmani provides a clear walkthrough in his screencast.

## [Codiqa](http://www.codiqa.com/)

![](https://lh4.googleusercontent.com/l9BsWtGJ6NBQzTQbkHwhoYCCw1P26jr5fJDqTXKXFa18HgIDvc3_mrMMwC08xV3gLr6uMAdsRH1XA-DswwmViVb1cfUlaC-5aE27nQO0miZc4LrV5Sw)
